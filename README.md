## Proyectos destacados

### 01 · AgroSmart — Gestión agrícola + AI Automation

**Objetivo:** centralizar el seguimiento de cultivos y facilitar la gestión de actividades agrícolas.

**Solución técnica:** plataforma con monitoreo de cultivos en **3D**, **Agentic Workflows** y un **AI Chatbot impulsado por n8n**. Integra servicios con **EmailJS** y **Cloud Deployment en Render** para conectar la gestión agrícola, la automatización y la atención al usuario.

**Stack:** n8n · AI Chatbots · Agentic Workflows · Integración de APIs · EmailJS · Render.

[**Ver código base →**](https://github.com/Thorling006/AgroSmart) · [Evolución del backend en Python / FastAPI — en pruebas](https://github.com/Thorling006/AgroPython)

### 02 · NovaTech-Solutions — Full-Stack + Cloud Deployment

**Objetivo:** centralizar inventario, ventas y logística para facilitar el control de las operaciones de una empresa.

**Solución técnica:** aplicación **Full-Stack** con backend en **PHP / Laravel** y frontend en **Vue.js / Inertia.js**. Conecta la información del negocio con **PostgreSQL en Supabase** y utiliza **Railway y Render** para su despliegue en la nube.

**Stack:** PHP · Laravel · Vue.js · Inertia.js · SQL · PostgreSQL · Supabase · Railway · Render.

[**Ver código →**](https://github.com/Thorling006/NovaTech-Solutions)

### 03 · Sistemas de Gestión y Ventas — Software empresarial
